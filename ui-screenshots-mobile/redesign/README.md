# Storefront preview

Generated by `npm run test:storefront` using intercepted API fixtures. Product names, prices, slides and checkout data here are test data, not real shop content.

- `home-390-viewport.png`: mobile first screen.
- `home-390.png`: mobile full page, 2 columns.
- `home-320.png`: narrow phone, 3 columns.
- `home-1440.png`: desktop, 6 columns.
- `menu-390.png`: scrollable drawer and blurred backdrop.
- `voucher-390.png`: voucher availability message.
- `home-fallback-390.png`: greeting when no slides are published.

Re-run the script with the app running at `http://127.0.0.1:4200` to regenerate.
