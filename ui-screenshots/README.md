# Meumip UI screenshots

Ảnh được chụp full-page ở chiều rộng 1440 px từ frontend `http://localhost:4200` và dữ liệu backend thật tại `http://localhost:8080`.

- `user-home`: trang chủ.
- `user-product`: danh sách và chi tiết sản phẩm.
- `user-cart`: giỏ hàng có sản phẩm.
- `user-checkout`: form thanh toán có tóm tắt đơn.
- `user-contact`: trang liên hệ.
- `user-auth`: đăng nhập và đăng ký.
- `user-orders`: danh sách và chi tiết đơn hàng của tài khoản.
- `admin-dashboard`: tổng quan quản trị.
- `admin-product`: danh sách, tạo mới và chỉnh sửa/chi tiết sản phẩm.
- `admin-order`: danh sách và chi tiết/cập nhật đơn hàng.

Có thể chụp lại toàn bộ bằng lệnh:

```powershell
node scripts\capture-ui.mjs
```
